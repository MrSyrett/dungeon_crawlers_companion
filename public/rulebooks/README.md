# Rulebooks

Drop rulebook PDFs in this folder and they appear automatically on the
**Rulebooks** page (/rules), linked from the dashboard.

The filename becomes the title, so:

    shadowdark-core-rules.pdf   ->  "Shadowdark Core Rules"
    dcc-core-rules.pdf          ->  "Dcc Core Rules"

Only `.pdf` files are listed. Use your own purchased copies — no rulebooks
are bundled with this app.
